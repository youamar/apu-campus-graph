08How it's built

Built on Google Cloud.
Grounded by design.

Browser

React + Vite

Single-page app. Living graph and Ask APU chat.

Google Cloud Run

Express API

Dockerised, deploy-ready. Sends the question and catalog to Gemini, then keeps only real club IDs.

Gemini

gemini-3.5-flash-lite

Structured JSON output

Catalog

137 real communities

Scraped from Student Affairs

Grounded answers

Only real club IDs ever reach the UI.

Offline fallback

A local matcher takes over, so the demo never dies.

Cloud Run ready

Dockerised and deploy-ready on Google Cloud Run.

Honest data

Sample values are clearly labelled as sample data.
